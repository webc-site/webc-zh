# 国际化语言状态管理

## `LANG_LI` : 支持的国际化语言列表数组。

## `langGet()` : 获取当前设定的语言标识信息。

### 返回值

当前语言标识 [lang_name, lang_id]

## `onLang` : 订阅语言变更事件。若当前已设定语言，将立即触发回调。

### 参数

- func : 语言变更时的回调函数。参数为当前语言标识 id，无返回值。

### 返回值

用于取消订阅的卸载函数。

## `langSet` : 设定当前语言标识并通知所有订阅者。

### 参数

- id : 目标语言标识 [lang_name, lang_id]
